# FocusPulse

FocusPulse is a browser-based study planner and focus tracker designed to help students organize their workload, stay consistent, and avoid burnout. It combines task planning, a focus timer, progress tracking, and motivational features in one simple interface.

## Features

- Task dashboard for adding and managing study tasks
- Auto-prioritization based on deadlines and effort level
- Built-in focus timer for deep work sessions
- Productivity score and streak tracking
- Profile page with study rhythm and progress insights
- Achievements page for badges and personalization
- Prototype login and signup flow with local browser persistence

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- LocalStorage for saving app state in the browser

## Project Structure

- `index.html` - main dashboard
- `achievements.html` - achievements and milestones
- `auth.html` - login and account creation page
- `styles.css` - shared styling across the project
- `script.js` - app logic, state handling, and UI updates
- `images/` - logo and badge assets

## Getting Started

1. Download or clone the project.
2. Open `index.html` in your browser.
3. Use the navigation bar to explore the dashboard, achievements, and login pages.

No installation or build step is required.

## Notes

- This project is a front-end prototype.
- User data is stored locally in the browser using `localStorage`.
- Authentication is simulated for demonstration purposes and is not connected to a backend.
